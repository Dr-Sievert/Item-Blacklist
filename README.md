# Item Blacklist

A Minecraft 1.21.1 mod built for Fabric and NeoForge from a shared common project.

## Projects

- `common` — loader-independent code shared by both versions.
- `fabric` — Fabric Loader entrypoint and Fabric-specific code.
- `neoforge` — NeoForge entrypoint and NeoForge-specific code.

The mod does not require a shared third-party runtime library such as Architectury API.
